# 《走出戈壁》前 20 页试点

## 直接查看

双击 [交互知识图谱](site/index.html) 即可在浏览器打开。页面使用本地 HTML、SVG、JavaScript，不依赖线上图库或图谱服务。`site/index.html`、`tmp/page-001.png` 至 `page-020.png`、原 PDF 要保持现有相对目录关系，才能从关系证据跳到原页。知识图谱数据另存为 [graph.json](data/graph.json)，便于后续扩充或导入 Neo4j 等系统。

图谱包含 65 个节点、67 条关系，节点类型为人物、事件、时间、地点。每条关系都附有 PDF **物理页码**、该页短引文、所属部分；仁川登陆节点另附美国国家档案馆的[独立核对资料](https://www.archives.gov/calendar/event/korea-75-macarthur-s-gamble-the-inchon-landing)。目前其他历史陈述均表示为“书中叙述”，并不等同于独立史实校验。

## 处理链与质量

1. 将扫描 PDF 的前 20 页渲染为 300 dpi 灰度 PNG。
2. 用本机 PaddleOCR PP-OCRv6 small 做主 OCR；另用 Tesseract 对 6 页对照。
3. 保存逐页 OCR 文本、坐标与置信度 JSON，并对两段正文人工校对。[质量样本](ocr/quality_sample.json)共 547 字：Paddle 编辑差异 3 处，Tesseract 10 处。此数值不代表全书准确率。
4. 人工挑选试点实体、事件与关系；[构建脚本](build_graph.py)对每条引文检查它出现在相应页的 OCR 文本中。关键节点可从页面直接打开扫描页核对。
5. [HTML 构建脚本](build_site.py)将图谱 JSON 内嵌到 HTML，浏览时无需运行 Python。

OCR 文本仍有标点、专名和图片噪声，且图谱只覆盖前 20 个物理页。作者简历和自序中关于后期经历的内容虽在试点页内，但这些事件的具体时间和背景仍需在全书后续章节补证。带 `?` 的时间为按文中相对描述推算，保留不确定性。

安装路径、版本、耗时、内存及复现命令见 [OCR 安装与资源实测](../OCR安装与资源规划.md)。
