# 人生节点地图：时代、选择与共同经历

## 叙事问题

时代怎样改变单伟建的处境和可选择的道路？他作了什么选择，谁提供支持，谁仍受到限制？

地图围绕这组问题组织，而不是把职位、地点和日期堆成履历。历史背景具有解释作用：知识怎样被评价、生产资源怎样分配、大学录取由谁决定、跨国求学有哪些门槛、判断怎样随信息改变。

## 两卷主干

原书八个关节：父辈的期待 → 教育被打断 → 劳动与组织 → 离开的关口 → 教育重新打开 → 学习、援助与家庭 → 观察改革，转向实践 → 重返共同的过去。

第07关另接书外续篇：金融业角色 → 韩国第一银行 → 深圳发展银行 → PAG与团队 → 写作与传承。它从1993年接起，与原书2005年的回望结尾并列，避免将阅读顺序误读为单向年代顺序。

## 可见的结构

桌面画布以四列两行的回折路线安排主干，数字和箭头表示阅读顺序。每个主干上方是一个命名的时代/制度节点，下方是两条命名的具体人物或事件。背景线条用虚线，主线用铜金色实线，局部分支用细线。地图位置没有地理坐标含义。

主线和关键支线默认全部存在，没有点击后才出现的新关卡。地图使用分层的自由节点簇：中间的章印、上方历史题签、下方人物支路。关系标签说明作用，不使用没有语义的网状连接。

当前实际为41个可见节点；65项内容包括从详情继续回到的原书场景。正文不把每一个场景都变成同等大小的地图节点，以免重新淹没主干。

## 阅读层次

1. 看全景：每个主干一个问题、一句核心处境。
2. 看详情：3段正文、阅读解释、原书引文；关键招生节点另有五道关口示意。
3. 看他人：人物自己的处境、承担与边界，不只列“贵人”。
4. 看证据：按章阅读器、准确PDF页、官方记录和访谈链接。

正文中人物的行为、宏观解释与编者联系有不同证据强度。制砖机未落实、1975年推荐入学不等于1977年高考、1989年身在美国获知事件、2005年留下者的处境，都是需要保留的叙事限制。

## 放映

用户新增的放映需求对应17幕：关键关节03、04、06、07各用两幕讲清处境与转折，其余一幕。每幕35—55秒范围内，现稿40—50秒，总740秒。画面停留给阅读，不逐字打字，不用随机动画或持续运动抢占注意力。用户明确点击后才自动播放。

每幕固定显示所属主关节、日期、处境、经历与一句阅读理解。底部保留13个主干章节的位置，允许直接跳转。暂停时保留本幕已播放时间，切幕从头计时；最后一幕停住，允许重播；切至后台会暂停。

时代插画覆盖学习中断、戈壁劳动和跨洋求学，其余场景穿插真实原书照片、作者肖像与著作封面。AI图不是史料，原书图不裁掉原注。没有旁白、音效或把回忆模拟成现场影像。

## 技术

静态HTML内嵌JSON、CSS和JavaScript；SVG仅负责真实的图示路径，栅格图负责艺术背景。没有力导向布局、地理底图、远程CDN、在线字体或运行时请求。

节点、原书场景、历史解释、外部来源与放映脚本分别组织。共享ID使地图、详情、放映相互定位。宽屏详情保留地图，窄屏内容按语义顺序重排。放映有键盘操作与焦点约束，尊重系统减少动态效果偏好。

## 完成标准

- 原书八个关键转折及命名支线可直接看到。
- 深入内容说明作用和代价，能够返回原书或外部依据。
- 后来的交易既包含角色、条款和机构，也保留失败自述与共同参与者。
- 自动放映可暂停、续播和退出，地图与放映的位置互通。
- 所有资源本地可用，核查过程不依赖最终读者联网。
