# 《走出戈壁》人物传记带读

打开 [dist/index.html](dist/index.html)。这是本地静态页面，无需安装新的应用、Python库或前端依赖；读取、定位和交互均在本机完成。

## 阅读方式

默认进入一条连续的带读主线：认识人物 → 原书中的十段经历 → 五段书外续篇 → 回看与继续探索，共17个短步骤。每步围绕一个问题，展示正文、编辑归纳和对下一步的承接；底部提供一个明确的继续按钮。

阅读目录收起在右上角，地图从当前位置按需打开。关键人名可从正文点开，照片与书封按经历出现；具体场景、更多人物和证据保留在补充阅读区。关闭补充阅读仍回到原步骤，阅读位置仅存在本机浏览器中。若浏览器不允许本地文件使用存储，顺序阅读与地址中的步骤定位仍可使用。

没有自动播放、网络地图瓦片或外部字体。地图采用 Natural Earth 海陆轮廓，坐标为城市或地域示意，不定位无法确认的旧址。照片保留原书整页，可放大阅读图注；新增作者官网肖像与两张著作封面均已下载在本地，附出处。阅读外部原始材料时需要联网。

## 目录与重建

- `GUIDED_READING.md`：根据读者反馈制定的当前带读方案。
- `DESIGN.md`：第一版地图方案，保留为设计记录。
- `data/story.json`：7幕、34场景、15组人物资料及原书证据。
- `data/guide.json`：17个带读步骤、10条书外资料来源、网络影像记录。
- `src/`：页面、样式和交互脚本。
- `assets/`：海陆轮廓及来源说明。
- `dist/`：可直接打开的成品，HTML内嵌数据、地图、脚本和样式，原书图片在相邻的 `assets/` 中。

```powershell
python biography/scripts/build_site.py
node --check biography/src/app.js
node biography/scripts/check_render.cjs
```

构建只需要Python标准库；Node仅用于开发检查，打开页面不需要它。

若拷贝到别处，整体保留 `biography/dist/` 即可阅读地图；要使用全书与扫描页链接，还需保留项目当前目录结构中的 `book_reader/site/dist/` 和根目录原PDF。

## 校验与范围

构建前逐一验证34段引文能在其标注的PDF页文字稿中找到，检查全部场景、人物、地点引用及照片；17步带读覆盖全部既有场景，书外步骤须有具体来源。JavaScript冒烟检查覆盖前后导航、目录收束、原步骤保持、本机续读、所有地图和补充面板、来源链接及10张本地图片。网络图片已检查画面，未执行浏览器排版或点击测试。

文字稿尚未逐字人工校勘，引文匹配不能代替扫描原件复核。原书内部日期差异在对应场景出处中说明。原书正文至1993年、后记至2005年；书外续篇回到1993年的职业路口，补读金融业、新桥的两笔银行交易、PAG和写作。事实与编辑理解分别呈现，任职核查日期为2026-09-22。

第一版使用3个Sub-Agent细读全书；本轮使用1个继承当前模型和推理级别的Sub-Agent研究书外资料与网络影像。主Agent完成核查、内容编排和页面。没有额外安装或切换模型。页面未发布到外部服务；`.openai/hosting.json`只声明静态输出目录，不包含云端站点ID。
