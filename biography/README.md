# 《走出戈壁》人生节点地图与沉浸放映

打开 [dist/index.html](dist/index.html)。页面、正文、脚本与影像均在本地运行，无需安装依赖或连接网络。打开外部来源网页时才需要联网。

## 两种互通的阅读方式

- **全景地图**：8个人生关节以金色路线相连，每个关节的时代背景与两条人物/事件支线直接可见。书外5个关节在下一段续接，共41个可见节点。点选后在侧栏深入，关闭后回到原视野。
- **人生放映**：顶部“放映人生”进入17幕全屏阅读，按“时代与处境 → 他的经历 → 阅读理解”展开。手动前后切换，或点击自动放映；总时长12分20秒，可暂停，离开浏览器标签页自动暂停。支持左右方向键、空格与Esc。
- **放映与地图**：每幕显示所属人生章节，可跳到任一章节；“在地图中展开”回到对应节点。节点详情也能直接放映这一段。
- **贯穿线索**：教育缺口、帮助的延续、规则的作用、机会的差异；点选后显示具体关联节点，不在地图上堆叠跨越全屏的连线。

放映为图片与文字的幻灯片式阅读，没有自动生成的旁白。桌面宽屏采用人工编排的节点图，可缩放与拖动；窄屏按同样语义顺序重排为两列或一列，保留所有主干与支线。没有解锁、积分或必须逐关点击的限制。

## 资料与影像

- `data/story.json`：原有34个原书场景、15组人物、7张原书照片，均保留可访问入口。
- `data/atlas.json`：65项可读内容，含8个主关节、深入历史机制与人物支线、5个书外关节和4个进一步的故事。17项网络资料均列明来源。
- `data/cinema.json`：17幕脚本、逐幕影像、时长与图像性质说明。
- `assets/SOURCES.md`：原书影像、作者官网肖像及封面、4张AI氛围插画的出处。

原书引文44条（含既有34条）逐条匹配带页码文字稿。匹配不能代替扫描原件校勘。正文区分当事人回忆、同期文件与阅读分析，重要边界放在对应节点的“依据与原文”内。原书正文以1993年为止，后记回望2005年；书外续篇明确从1993年重新接起，延伸至后来的投资、奖学金与写作。

AI图片只作年代氛围的艺术表达，不声称复原作者的真实教室、书桌或营房；每幕均有明确标示。原书照片以整页显示，保留图注。海陆轮廓不再进入页面，旧GeoJSON只保留在历史资产中。

## 构建与检查

```powershell
python biography/scripts/build_site.py
node --check biography/src/app.js
node biography/scripts/check_render.cjs
```

构建仅用Python标准库；Node只供开发检查，用户打开HTML不需要它。

构建前校验引文、全部节点引用、来源、图片、放映顺序和文字长度。Node检查覆盖65个详情、41个可见节点、34个场景入口、17幕放映、播放与暂停/续播/结束/重播、后台暂停、放映与地图的上下文保持、深链接和离线资源。Node检查不等同于浏览器排版检查。

分发时保留整个 `dist/`；若需要打开完整原书与扫描页，还应保留原项目相对目录中的 `book_reader/site/dist/` 和根目录PDF。
