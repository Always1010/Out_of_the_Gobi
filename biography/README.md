# 《走出戈壁》人物传记地图

打开 [dist/index.html](dist/index.html)。这是本地静态页面，无需安装新的应用、Python库或前端依赖；读取、定位和交互均在本机完成。

## 阅读方式

从全程理解主要地点迁移，再进入七幕人生。每一幕包含当时处境、原书照片和具体场景；场景可展开人物的实际作用、原文短引文和扫描页出处。人物与「求知／相助／选择」线索可以跨越章节重新组织阅读。

没有自动播放、网络地图瓦片或外部字体。地图采用 Natural Earth 海陆轮廓，坐标为城市或地域示意，不定位无法确认的旧址。照片保留原书整页，可放大阅读图注。

## 目录与重建

- `DESIGN.md`：实现前制定的信息架构、选材原则与交互方案。
- `data/story.json`：7幕、34场景、15组人物资料及原书证据。
- `src/`：页面、样式和交互脚本。
- `assets/`：海陆轮廓及来源说明。
- `dist/`：可直接打开的成品，HTML内嵌数据、地图、脚本和样式，原书图片在相邻的 `assets/` 中。

```powershell
python biography/scripts/build_site.py
node --check biography/src/app.js
node biography/scripts/check_render.cjs
```

构建只需要Python标准库；Node仅用于开发检查，打开页面不需要它。

若拷贝到别处，整体保留 `biography/dist/` 即可阅读地图；要使用全书与扫描页链接，还需保留项目当前目录结构中的 `book_reader/site/dist/` 和根目录原PDF。

## 校验与范围

构建前逐一验证34段引文能在其标注的PDF页文字稿中找到，检查全部场景、人物、地点引用及照片。JavaScript冒烟检查覆盖七幕的三种地图范围、全部深入阅读面板、来源链接和本地资源，未执行浏览器视觉或点击测试。

文字稿尚未逐字人工校勘，引文匹配不能代替扫描原件复核。原书内部日期差异在对应场景出处中说明。完整传记范围以原书正文至1993年、后记至2005年为准；本页未扩展为后续投资生涯综述。

本次使用3个继承当前模型和推理级别的Sub-Agent并行细读互不重叠的章节。主Agent完成选材整合、出处校验、视觉与代码。没有额外安装或切换模型。页面未发布到外部服务；`.openai/hosting.json`只声明静态输出目录，不包含云端站点ID。
