# 《走出戈壁》人物传记地图：内容与交互方案

2026-09-22。依据 `book_reader/text/simplified/` 中保留 PDF 页码的全书稿及原书图注制定。方案在完整页面实现前形成。

## 阅读目标与叙事判断

读者先能说清单伟建从哪里走到哪里、每次迁移为什么发生，再理解那些改变机会的行动、制度条件和具体的人。原书第六至二十一章集中于戈壁经历，这段人生应得到足够篇幅；正文结束于 1993 年赴香港，后记回到 2005 年的戈壁。地图以这个往返结构收束，不把有限的作者简历扩写成投资履历，也不把回忆录处理为只通向成功的故事。

以地点为入口、以处境和转折为叙事单位。地图只画迁移路线与当前相关地点；人物关系由场景中的作用来表达。一个人的意义来自他如何与作者一起行动、相助、冲突或承受不同命运。

## 交互如何支持理解

首屏展示整体地理旅程，旁边用一段短文说明人生轮廓；七幕入口直接可见。点击某一幕，地图切到相关地域，阅读区呈现当时处境、几个关键场景和这一幕的变化。前后幕按钮让读者顺着故事读，也可以随时回到全程。

点击场景展开完整短叙事：发生了什么、作者面对什么条件、采取什么行动、结果如何。事件证据和原文短引文放在可展开的出处区，附章节及 PDF 物理页链接。地理标记同时突出事件所在地。

人物从场景中进入：例如刘小彤与交流读书、劳动和照片的保存有关；于医生不仅教医术，还在升学体检时相助；石滨贯穿婚姻、跨洋分离与团聚。人物面板列其相关场景和具体作用，不显示抽象的连线密度。

三个可选阅读线索为“求知”“相助”“选择”。它们提供跨越各幕的相关场景入口；连接表示主题呼应，只有原书明确支持时才使用因果表述。

## 地图、图片与视觉

采用海蓝、墨色和少量琥珀色，地图和书页形成清楚的视觉分工。真实海陆轮廓来自 Natural Earth 公共领域数据；不依赖在线地图瓦片。迁移线表示地点之间的叙事联系，不声称是精确航线或旅行轨迹。

城市点使用城市级示意坐标；乌梁素海和乌拉特前旗为地域级标注。没有可靠定位的旧营房、工具棚和砖窑不伪造经纬度，放在区域说明和事件文字中。地点视图允许在中国、美国与全程之间切换；戈壁篇通过场景和原书图片补充地方细节。

只使用本地原书照片，保留原图注与页码；照片是当时环境和人物的证据，不生成历史人物的替代肖像。正文使用不小于16px的文字；常用按钮与标签不小于14px。移动端将地图和阅读区改为上下结构。

## 数据与真实性

数据分为阶段、场景、人物、地点、主题与证据。场景是主要组织单位，阶段只做编排；同一人物、地点或主题可以关联多个场景。

- 原书事实：注明章节、PDF物理页和精确短引文，构建时校验引文能在来源页找到。
- 编辑解释：例如“这次经历改变了什么”，与原文引文分开呈现，避免把理解写成作者原话。
- 不确定信息：保留“期间”“约”“书中未注明”等表述；不使用推算出来的精确年月日。
- 资料冲突：如婚姻回忆中的年份冲突，优先采用完整、明确的登记日期，并在来源说明记录冲突。
- 叙事范围：正文至1993年，后记至2005年；不为增加人物数量而扩展无关宏观政治人物。

## 技术与分工

以本地静态 HTML、CSS、JavaScript 和 SVG 实现。整理后的 JSON 是唯一内容源；Python 构建器将数据、地图轮廓和程序内嵌进 HTML，图片放在相邻目录。打开后无需服务或 API；已有全书阅读器作为深入阅读入口。此次交付沿用本地文件方式。

3个 Sub-Agent 独立细读第1–10章、第11–21章、第22–29章与后记，继承当前模型与推理级别；它们只返回可核查的研究材料。主 Agent 负责选材、处理跨章节矛盾、方案与全部页面代码。内容研究并行，选材整合、数据校验、页面实现与最终提交串行。

## 完成标准

读者在概览能识别人生的主要地域迁移；进入任一幕能理解关键处境及变化；打开人物能看到其真实作用；重要陈述可回查原书。静态校验覆盖引文页码、人物/地点引用、阶段顺序、全部本地资源及 JavaScript 语法。浏览器测试未被单独要求，不把它列为已完成验证。
