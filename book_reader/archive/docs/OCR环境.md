# 历史 OCR 环境记录

2026-09-22 全书采集快照，2026-10-12 整理为可移植说明。不是日常电子书或网站构建的安装要求。

| 项目 | 历史版本/用途 |
| --- | --- |
| Python | 3.11.9，单独虚拟环境 |
| OCR | paddleocr 3.7.0、paddlepaddle 3.3.1、paddlex 3.7.2 |
| 模型 | PP-OCRv6_small_det、PP-OCRv6_small_rec |
| 备用工具 | Tesseract 5.4.0.20240606 与 chi_tra/eng 语言数据；现行采集脚本不调用它 |

旧机器曾因中文模型路径解析出错而使用 ASCII 缓存位置；具体机器路径不再保留。当前采集工具支持配置 PDF、模型和缓存路径，使用方法见 [归档工具](../README.md)。渲染依赖 PATH 中的 Poppler `pdftoppm`。模型缓存可再下载或从自己的备份恢复，不要求特定盘符或用户名目录。

已保存 OCR JSON 是校验和重建证据，正常导出无需原扫描或安装 PaddleOCR；不要为了恢复这个历史环境重做现有校订稿。
